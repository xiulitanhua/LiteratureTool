## 1. 软件简介

LitBox 是一个文献搜集与整理工具，解决写论文时"从清单到规范命名的 PDF"全流程问题：

```
文献清单(Excel) → ① 获取 DOI → ② 下载 PDF → ③ 智能命名 → ④ 输出报告
                        ↑              ↑            ↑
                     常规来源失败时 → DeepSeek AI 自动兜底
```

**核心能力**：
- 自动识别 Excel 中的文献字段（标题/作者/年份/期刊/DOI）
- 通过 Crossref / OpenAlex 为文献匹配 DOI
- 多渠道下载 PDF（官方报告 → tesble → doi.org → Unpaywall OA → Sci-Hub）
- 自动按「作者_年份_期刊缩写_研究区域_题名」规范命名
- **DeepSeek AI 集成**：常规方法搜不到时，AI 语义补全（找 DOI、找 OA 链接、补元数据）
- **AI 对话代理**：直接和 AI 对话，选中文献自动搜 DOI / 下载，按主题批量搜集文献

## 2. 安装与启动

### 2.1 环境要求
- Windows 10/11（64 位）
- 无需安装任何运行环境（已打包 Python 运行时）

### 2.2 文件组成
```
LitBox.exe         主程序
config.json        配置文件（存放 DeepSeek API Key，首次运行自动生成）
```

### 2.3 启动
- 双击 `LitBox.exe` 即可。
- **注意**：首次运行会在 exe 同级目录生成 `config.json`。请把整个文件夹放在你有写权限的位置（如 `D:\` 下），不要放 Program Files。

## 4. 快速上手

1. **准备 Excel**：一列是文献标题（表头写 `标题` / `TITLE` / `题名`），建议同时有作者、年份、期刊列。
2. **选择 Excel** → 点击「选择 Excel」→ 选择文件 → 点击「检测字段」确认识别正确。
3. **一键处理** → 点击「一键处理」，自动完成 DOI 获取 + PDF 下载。
4. **查看结果** → PDF 在输出目录的 `Downloaded_PDFs` 文件夹；Excel 更新了 DOI/PDF 链接列。
5. **可选**：PDF 重命名 → 对已有 PDF 统一命名。

## 5. 核心功能详解

### 5.1 导入与字段检测
- 支持 `.xlsx` / `.xls` 格式。
- 自动识别：标题、年份、作者、期刊、DOI、研究区域、期刊缩写、PDF 链接。
- 识别失败时，把表头改成以下写法之一：
  - 标题：`标题` / `TITLE` / `Title` / `题名` / `篇名`
  - 年份：`年份` / `YEAR` / `Year` / `发表年` / `出版年`
  - 作者：`作者` / `Author` / `AUTHOR`
  - 期刊：`期刊` / `Journal` / `刊名` / `来源`
- 表格无标题列会提示错误。

### 5.2 获取 DOI
- 匹配顺序：**Crossref → OpenAlex**。
- 标题匹配度 ≥ 阈值（默认 80%，可在设置页调整）才写入。
- 输出 4 列：`DOI` / `DOI链接` / `匹配度` / `DOI来源` / `DOI状态`。
- 生成文件：`原文件名_已加DOI.xlsx`。
- **AI 兜底**（已配置 Key 时）：上述两个来源失败 → 自动执行机器核验找回（Crossref 标题检索）→ 仍失败再调 DeepSeek → **AI 结果必须通过 Crossref 核验**（存在 + 标题相似度 ≥ 60%）才写入，防止 AI 编造 DOI。

### 5.3 下载 PDF
- 下载源顺序（按"先免费后付费"）：
  1. 官方报告直连（ODP/DSDP 等 10.2973 系）
  2. tesble.com 镜像
  3. doi.org 直链（解析页面找 PDF 链接）
  4. Unpaywall OA 镜像
  5. Sci-Hub
  6. **AI 提供的 OA 链接**（机器核验的 OA 直链 → 无则问 DeepSeek）
- 每篇下载间隔 1.5~3.5 秒随机延迟，防止被封。
- 下载后自动用网页元数据 + PDF 元数据优化文件名。
- 生成文件：`原文件名_WithLinks.xlsx`，`PDF链接` 列可点击跳转。
- **断点续传**：已存在的文件自动跳过，中断后重跑可继续。

### 5.4 PDF 重命名
- 适用：已有 PDF 但命名混乱，想按清单统一命名。
- 流程：导入 Excel → 点「PDF 重命名」→ 选 PDF 文件夹 → 预览 → 确认执行。
- 命名格式：`作者_年份_期刊缩写_研究区域_题名简写.pdf`
  - 例：`Bjerga_2022_G3_HighlyDepletedSubductionModifiedMantle.pdf`
- **命名模式**（设置页选择）：
  - 本地命名（默认）：Excel → Crossref → PDF 元数据 → 标题兜底，离线快速
  - AI 命名：本地链路缺字段时，调 DeepSeek 补全元数据再命名

### 5.5 一键处理
- 自动执行：获取 DOI → 保存 → 重新加载 → 下载 PDF → 生成报告。
- 适合清单齐全的批量任务。

## 6. AI 功能详解

### 6.1 AI 补全配置（设置页）

1. 进入「设置」→ 滚动到「🤖 AI 补全（DeepSeek）」卡片。
2. 填入 **API Key**（在 [platform.deepseek.com](https://platform.deepseek.com) 注册充值后获取）。
3. 勾选「启用 AI 补全」。
4. 点击「测试连接」验证 → 点击「保存配置」。
   - 说明：Base URL 默认 `https://api.deepseek.com`，模型默认 `deepseek-chat`，一般不用改。
   - 现在即使不点"保存配置"，打开 AI 对话时也会自动同步已填的 Key。

### 6.2 AI 自动兜底（无需操作，自动触发）

| 场景 | AI 行为 |
|---|---|
| DOI 匹配失败 | AI 根据标题+作者+年份报 DOI → 核验后写入 |
| PDF 下载失败 | AI 提供 PMC/arXiv/机构库等 OA 链接并自动尝试 |
| 命名信息缺失 | AI 补全作者/年份/期刊缩写/研究区域 |

**防编造机制**：AI 给出的任何 DOI 都必须通过 Crossref 核验（DOI 真实存在 + 标题相似度 ≥ 60%），否则拦截并标记 `AI建议(未核验)`。

### 6.3 AI 对话窗口

- 打开方式：顶部导航「AI 对话」（再点一次关闭）。
- 功能：
  - 直接提问（Ctrl+Enter 或点「发送」）
  - 📎 引用选中文献：把表格选中行的信息附加到问题中
  - 🔍 批量搜文献：按主题自动搜集文献（见 6.5）
  - 🧹 清空对话
- 引用文献后可问："这篇文献的正确 DOI 是什么？""有开放获取版本吗？"等。

### 6.4 AI 代理：选中文献自动搜 DOI / 下载

1. 在总览页表格**选中一行文献**。
2. 右侧「选中文献详情」底部出现两个按钮：
   - **🔍 搜索 DOI**：自动执行 Crossref 检索 → AI 兜底 → 核验 → 写入 Excel
   - **📥 AI 搜集下载**：自动查 OA 镜像 → 问 AI → 下载 → 重命名 → 写入 PDF 链接列
3. 点击后自动打开 AI 对话窗口，**实时展示思考过程**（第几步、命中什么、结果如何）。

适用场景：某条文献在批量处理时失败了（DOI 状态为"获取失败"），选中它单独补救。

### 6.5 批量文献搜集（说一句自动找文献）

1. 打开「AI 对话」→ 点「🔍 批量搜文献」。
2. 输入主题，例如：
   - `找 2020 年以来北大西洋中脊地幔熔融的文献，找 15 篇`
   - `关于深海热液喷口微生物群落的综述文献，找 10 篇`
3. AI 自动解析出英文关键词 + 年份范围 + 数量。
4. 自动调用 Crossref 搜索，候选文献以列表展示。
5. **勾选**要的文献 → 点「导入选中的到 Excel」。
6. 自动去重（已存在的 DOI 跳过），追加到当前表格，并保存 `_批量搜集.xlsx`。

### 6.6 文献核验机制（内置三工具）

按《文献批量下载通用方法》实现：
- **Semantic Scholar**：最快核验 + 附赠 OA 直链（限流约 1 次/秒）
- **Unpaywall**：OA 镜像权威
- **Crossref**：标题权威核验

用途：验证 DOI 是否标错、找回真实 DOI、找 OA 免费版。

## 7. 文献补全方法（搜不全时怎么办）

### 第一层：AI 自动兜底（工具内置）
常规来源失败时自动触发（见 6.2），零操作。

### 第二层：半自动核对
- 看表格 `DOI状态` 列：`获取失败` / `AI建议` 的行需要人工处理。
- 选中失败文献 → 点「🔍 搜索 DOI」或「📥 AI 搜集下载」单独补救。
- 或用「批量搜文献」按主题重新找。

### 第三层：人工检索（自动+AI 都失败时）
1. **标题变化**：试缩写/全称、大小写、中英文互译、关键词组合。
2. **数据库交叉**：英文用 Google Scholar / Crossref / Semantic Scholar；中文用 CNKI / 万方。
3. **免费获取**（按优先级）：期刊官网 → PMC → arXiv → 机构知识库 → ResearchGate → 作者主页 → 邮件向作者索取。
4. **馆际互借**：单位图书馆文献传递、CALIS、NSTL。

> 完整方法见同目录《文献补全方法.md》。

## 9. 常见问题 FAQ

**Q1: 打开 exe 报"没有 tkinter"？**
用错版本了。v3.6 已打包完整运行环境，请确认使用的是 `D:\...\dist_v36\LitBox.exe` 或桌面最新版（86MB 左右）。37MB 的是 v3.4 旧版。

**Q2: 设置页看不到"保存配置"按钮？**
设置页支持滚动——用鼠标滚轮或拖右侧滚动条向下滚。v3.6 已修复该问题（可滚动设置页）。

**Q3: 点了「AI 对话」没反应/提示未配置？**
在设置页填入 API Key 并勾选"启用 AI 补全"，或检查 `config.json`（exe 同级）里的 `deepseek_enabled` 是否为 true、`api_key` 是否为空。

**Q4: AI 给出的 DOI 是错的？**
v3.6 已内置核验——AI 的 DOI 必须通过 Crossref 核验才写入。若显示"AI建议(未核验)"，请人工在 `doi.org/<DOI>` 验证。

**Q5: 下载很慢/下载失败？**
- 每篇有 1.5~3.5 秒延迟防封，量大时请耐心。
- 失败文献可选中后用「📥 AI 搜集下载」单独补救。
- 部分文献在付费墙后，工具无法免费获取，需机构 VPN 或人工渠道。

**Q6: Excel 表头识别不对？**
把表头改成标准写法（见 5.1），重新导入。

**Q7: 会消耗多少 API 费用？**
只有常规来源失败时才调用 AI，正常情况 0 成本。每条 AI 请求约 0.001~0.003 元，批量全失败兜底 100 篇约 0.5 元以内。

**Q8: config.json 里的 API Key 安全吗？**
明文存在本地文件。请勿把该文件分享给他人；发布给别人时请清空 Key。
