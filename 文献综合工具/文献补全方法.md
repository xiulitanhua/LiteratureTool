# 文献补全方法手册（LitBox v3.5 配套）

> 当常规渠道（Crossref/OpenAlex/tesble/doi.org/Sci-Hub）搜不全文献时，
> 按本手册的分层方法补足缺失文献。LitBox v3.5 已内置 DeepSeek AI 自动兜底，
> 本手册面向"自动兜底仍失败"的人工补全程。

---

## 第一层：AI 自动兜底（工具内置，零操作）

在设置页填入 DeepSeek API Key 并启用后，工具会在三个环节自动补全：

| 环节 | 触发时机 | AI 行为 |
|---|---|---|
| 找 DOI | Crossref/OpenAlex 匹配失败 | 根据标题+作者+年份直接报 DOI，置信度 ≥70% 写入 |
| 找 PDF | tesble/doi.org/Sci-Hub 全失败 | 给出 PMC/arXiv/机构库等 OA 链接并自动尝试 |
| 补元数据 | 作者/年份/期刊/研究区域缺失 | 补全字段，文件名更规范 |

**注意**：置信度低于 70% 的 AI 结果只标记 `AI建议(置信度xx%)`，不写入——这类条目需要你人工核对（见第三层）。

---

## 第二层：半自动核对（工具辅助，需人工确认）

### 2.1 看"未匹配"清单
DOI 获取完成后，日志和弹窗会报告未匹配数量；结果表格中 `DOI状态` 列标记为
`获取失败` 或 `AI建议` 的行就是需要人工处理的。

### 2.2 核对 AI 建议
对标记 `AI建议` 的条目：
1. 复制 AI 建议的 DOI → 浏览器打开 `https://doi.org/<DOI>`；
2. 若页面标题与你的文献一致 → 手动把 DOI 填入 Excel，重新运行；
3. 若跳转错误 → 丢弃该建议。

### 2.3 用 AI 二次提问（工具外）
对仍失败的条目，直接把标题+作者+年份发给 DeepSeek/其他大模型，追问：
- "这篇文献的 DOI 是什么？给我权威来源链接。"
- "这篇文献在哪个数据库？给出 Google Scholar 链接。"
- "是否有预印本或开放获取版本？"

## 第三层：人工检索（自动+AI 都失败时）

按以下顺序排查，命中即止：

### 3.1 标题变化
- 英文文献试**不同标题写法**：缩写/全称、大小写、连字符。
- 中文文献翻译成英文再查（反之亦然）。
- 用标题的关键词组合而不是整句搜索。

### 3.2 数据库交叉验证
| 文献类型 | 优先数据库 |
|---|---|
| 英文期刊 | Google Scholar / Crossref / OpenAlex / Semantic Scholar |
| 中文文献 | CNKI（知网）/ 万方 / 维普 |
| 会议论文 | IEEE Xplore / ACM / Springer / 会议官网 |
| 学位论文 | CNKI 博硕 / ProQuest / 国家图书馆 |
| 预印本 | arXiv / SSRN / bioRxiv / ResearchGate |

### 3.3 免费获取 PDF 的渠道（按优先级）
1. **期刊官网**：OA 论文直接可下；非 OA 找 `PDF` 或 `Full text` 按钮。
2. **PMC**：`https://www.ncbi.nlm.nih.gov/pmc/` 搜标题，生物医学文献覆盖率高。
3. **arXiv**：物理/地学/计算机预印本，`https://arxiv.org` 搜标题。
4. **机构知识库**：作者所在大学的 repository。
5. **ResearchGate**：搜标题 → "Request full-text" 向作者要全文。
6. **作者主页**：Google 搜 `作者名 机构 page publications`。
7. **Sci-Hub 镜像**（仅作最后手段，注意版权风险）：`https://sci-hub.se` 等。
8. **邮件索取**：找通讯作者邮箱，模板：
   > Dear Dr. [Lastname], I am a graduate student at the Second Institute of
   > Oceanography, MNR, China. I am very interested in your paper "[Title]"
   > and would be grateful if you could share the PDF. Best regards, [Name]

### 3.4 馆际互借与文献传递（学校渠道）
- 你所在单位（海洋二所/学籍单位）图书馆的**文献传递**服务；
- CALIS 文献传递、NSTL 国家科技图书文献中心；
- 通过导师/合作单位账号访问 Web of Science、Elsevier 等机构订阅。

---

## 第四层：预防性整理（长期习惯）

1. **建文献台账**：每篇文献记录 `标题/作者/年份/期刊/DOI/PDF路径/状态`。
2. **及时下载**：看到 OA 版本立刻下载，避免付费墙变化。
3. **规范命名**：统一 `作者_年份_期刊缩写_研究区域_题名.pdf`（LitBox 已内置）。
4. **定期备份**：PDF + Excel 清单双备份，防丢失。

## 快速决策表

| 情况 | 动作 |
|---|---|
| 无 DOI | 第三层 3.1 → 3.2 → 重跑 LitBox |
| 有 DOI 无 PDF | 3.3 的 1~6 条逐个试 → 7（谨慎）→ 8 |
| AI 建议低置信度 | 2.2 人工验证 |
| 中文文献 | 直接去 CNKI，别在 Crossref 上耗 |
| 极度冷门 | 3.4 馆际互借 / 找作者要 |
